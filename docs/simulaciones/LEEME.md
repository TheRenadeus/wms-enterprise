# Simulaciones

Maquetas interactivas para revisar una idea antes de construirla en el WMS. No se conectan a la API ni
a la base de datos: usan datos de ejemplo y guardan los cambios solo en el navegador.

## costos-prefacturacion.html

Simulación de la sección **Comercial**. Ábrela con doble clic en cualquier navegador.

- **Clientes:** condiciones de pago, precios especiales por cliente y guías de despacho con productos
  vendidos que todavía no se cobran. Desde aquí se prefacturan una o varias guías.
- **Costos y precios:** costo, precio de venta y margen de productos, insumos y servicios (almacenaje,
  operación y transporte), con un margen mínimo y un cálculo de precio por margen objetivo.
- **Prefacturación:** borrador con líneas de productos, insumos, transporte, servicios y otros cargos;
  descuentos, líneas exentas, IVA, margen interno y el flujo borrador → revisión → aprobada → facturada.
